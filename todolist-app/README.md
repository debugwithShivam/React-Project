# Todo List

The project contains a React/Vite frontend and an Express/MongoDB API.

- `todolist/` — frontend app. See its README for source layout and `VITE_API_URL` configuration.
- `todoList-backend/` — backend API. See its README for MongoDB and server configuration.

Start the backend with `npm run dev` from `todoList-backend/`, then start the frontend with `npm run dev` from `todolist/`.
